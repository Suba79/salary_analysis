
# Salary Analysis

Программа для анализа средних зарплат программистов в Москве
по данным Habr Career и SuperJob.

## Возможности

- Получение вакансий через API Habr Career и SuperJob.
- Поиск вакансий по 10 языкам программирования.
- Загрузка доступных страниц результатов.
- Расчёт предполагаемой зарплаты по указанным границам.
- Подсчёт средней зарплаты по каждому языку.
- Вывод статистики в виде таблиц в терминале.

## Требования

- Python 3.10 или новее
- API-ключ SuperJob

## Установка

Скачайте проект и откройте его папку в терминале.

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его в PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` в корневой папке проекта:

```env
SUPERJOB_API_KEY=your_secret_key
```

Получить ключ можно после регистрации приложения в SuperJob API.

## Запуск

```powershell
python main.py
```

Программа выведет две таблицы со статистикой:
Habr Moscow и SuperJob Moscow.

## Как рассчитывается зарплата

- Если указаны обе границы — используется их среднее.
- Если указана только нижняя граница — она умножается на 1.2.
- Если указана только верхняя граница — она умножается на 0.8.
- Вакансии без подходящих данных о зарплате исключаются из расчёта.

Статистика носит ориентировочный характер.
Результаты зависят от актуальных вакансий и полноты данных о зарплатах.
